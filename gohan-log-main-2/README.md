# ごはんログ

ご飯の写真を投稿して、一覧で見たり、いいねしたりできる試作品です。

## 今できること

- メールアドレスとパスワードでアカウント作成の流れを試す
- ログイン中の人として投稿する
- 投稿一覧をタイムラインとして見る
- 左に丸いアイコン、右に吹き出し投稿が並ぶタイムライン画面
- Xのような左メニューで、ホーム、検索、いいね、プロフィール、設定へ移動する
- プロフィール設定で、表示名、自己紹介、アイコン文字、アイコン色を変更する
- 自分の画像を選んで、拡大と位置調整をしてアイコンにする
- ホームタイムラインのアイコンを変更する
- 投稿ごとに、お店名と位置情報を追加するか選べる
- 位置情報の追加はデフォルトでオフ
- Netlifyで公開した場合、投稿、いいね、削除を全員で共有する
- Netlifyで公開した場合、投稿写真も共有保存して他の人の画面に表示する
- 不適切な投稿を通報する
- 通報が3件集まった投稿は自動で非表示にする
- 管理者が投稿を非表示にする
- 投稿にいいねする
- 投稿を共有する
- しゃもじアイコンの「めっちゃうまそう！やな！」で投稿を広める
- 自分がいいねした投稿を見る
- 食べ物名や説明文で検索する
- 自分の投稿を削除する
- 最初に作ったアカウントだけ、試作品上の管理者として全投稿を削除できる

## 大事な注意

`index.html` を直接開いている間は、アカウント、投稿、いいね、削除権限は「自分のブラウザ内だけ」で動く試作品です。

Netlifyで公開したURLでは、Netlify FunctionsとNetlify Blobsを使って投稿一覧と投稿写真を共有します。

メールアドレスとパスワードも本物のログインサーバーには送っていません。安全な本番版では、Supabase などの認証サービスを使います。

IPアドレスで削除権限を守る仕組みは、ブラウザだけでは安全に作れません。仲間全員で同じ投稿を見て、安全に削除権限を守るには、次にデータベースとサーバー側のルールを追加します。

位置情報は、投稿時にオンにした場合だけブラウザの許可を使って取得します。正確なお店の自動判定には、Google Maps APIなどの地図サービス連携が必要です。

## Netlifyで公開する

1. Netlifyの無料プランでアカウントを作成します。
2. `gohan-log-preview.zip` を Netlify Drop にアップロードします。
3. 発行されたURLを共有します。
4. 継続して共同作業する場合は、GitHubとNetlifyを連携すると更新が楽になります。

## 次に必要なこと

- 投稿を全員で共有するデータベース
- 写真を保存するストレージ
- 本物のメールアドレス認証
- 管理者だけが他人の投稿を削除できる権限設定
